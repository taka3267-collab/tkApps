GitHub の接続設定

公開するには GitHub のアクセストークンが必要です。トークンはこの端末のブラウザにだけ保存され、 GitHub 以外には送信されません。

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens で、リポジトリを tkApps のみ、権限を Contents: Read and write にして作成してください。
